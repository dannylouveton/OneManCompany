# Règles de l'entreprise en français

Traduction française des procédures par défaut (`company/operations/sops/`, `company/human_resource/sops/`).
Les noms d'outils, les formats JSON et les titres « Manager Archetype » / « Executor Archetype »
restent en anglais : le code les lit tels quels.

Pour passer une entreprise existante en français, copier ces fichiers par-dessus ceux de
`.onemancompany/company/` (en gardant une sauvegarde des originaux).
