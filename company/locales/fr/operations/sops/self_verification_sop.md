# Procédure d'auto-vérification avant de rendre un travail (SOP)

Après avoir produit ton livrable, vérifie une seule fois :

## Code / logiciel
- Relis attentivement ton code pour repérer les erreurs
- Si un bac à sable est disponible, utilise sandbox_execute_code pour l'exécuter une fois et corriger les erreurs
- Vérifie que tous les fichiers sont enregistrés aux bons chemins

## Documents / rapports
- Relis ton travail une fois avant de le rendre
- Vérifie que le contenu est complet et rangé au chemin prévu

## Règles générales
- Enregistre tous tes résultats dans l'espace du projet avec write()
- Ajoute une courte note de vérification à ton résultat
- Ne relis PAS des fichiers que tu as déjà lus
- Ne tourne PAS en boucle — vérifie une fois, puis termine
